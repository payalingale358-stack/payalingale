Scalar — Ek Akela Number

Sirf magnitude, koi direction nahi

📌 Definition

Scalar ek single real number hota hai. Koi dimension nahi hoti. Jaise temperature, price, age — ye sab scalars hain.

➕ Addition

3 + 5 = 8

Normal number addition. Koi special rule nahi.

✖️ Multiplication

4 × 3 = 12

Normal multiply. Scalar se vector/matrix multiply karna = scaling.

🔢 Scalar × Vector

2 × [3, 4] = [6, 8]

Har element ko scalar se multiply karo — isko "scaling" kehte hain.

💡 Data Science mein Scalar ka use:

Learning Rate (0.01), Loss value (0.35), Accuracy (0.95) — ye sab scalars hain!

3 × [2,5] = [6,15]

Vector ki length = Pythagoras theorem!

Python — Vector Operations
import numpy as np

# 2D Vectors banao
a = np.array([2, 5])
b = np.array([1, 3])

# Addition
print(a + b)        # [3, 8]

# Scalar multiply
print(3 * a)         # [6, 15]

# Magnitude (length)
print(np.linalg.norm(a))  # 5.385

Tensor — Multi-Dimensional Array

Matrix ka 3D ya zyada dimensions wala version

📌 Definition

Tensor ek generalized term hai — Scalar 0-D tensor hai, Vector 1-D, Matrix 2-D, aur 3D+ ko hum Tensor kehte hain. Deep Learning mein sab kuch tensors hain!

🖼️

Image Tensor

Ek color image = Height × Width × 3

Example: 28×28 image with RGB = shape (28, 28, 3)

📦

Batch Tensor

100 images ka batch = 100 × H × W × 3

Neural network ek baar mein 100 images process karta hai

🎬

Video Tensor

Video = Frames × H × W × 3

30fps video = 4D tensor with time dimension

Python — Tensor Examples
# Scalar (0-D Tensor)
s = np.array(5)
print(s.shape)       # () — koi dimension nahi

# Vector (1-D Tensor)
v = np.array([2, 5])
print(v.shape)       # (2,)

# Matrix (2-D Tensor)
m = np.array([[1,2],[3,4]])
print(m.shape)       # (2, 2)

# 3-D Tensor (jaise 2 images of 2x2 pixels)
t = np.zeros((2, 2, 3))  # 2x2 image, 3 channels (RGB)
print(t.shape)       # (2, 2, 3)

⚠️ Important Rules

• Vector add karne ke liye dono ka same shape hona chahiye.
• Matrix multiply: A(m×n) × B(n×p) = C(m×p) — inner dimensions match karna zaroori!
• A×B ≠ B×A matrix multiplication mein (non-commutative).

Transpose — Rows aur Columns Palat do

Aᵀ: matrix ko rotate karo 90° rotate karo

📌 Definition

Transpose mein rows aur columns swap ho jaate hain. Agar A ka element (i, j) hai, toh Aᵀ mein woh (j, i) par aayega. 2×2 matrix ka transpose bhi 2×2 hota hai.

📐 Transpose Properties

• (Aᵀ)ᵀ = A (do baar transpose = wapas same)
• (A+B)ᵀ = Aᵀ + Bᵀ
• (AB)ᵀ = BᵀAᵀ (order palat jaata hai!)

🔍 Symmetric Matrix

Agar A = Aᵀ hao toh matrix symmetric hai.
Example: [[1,2],[2,4]] — diagonal ke sath mirror image.

Python — Transpose
A = np.array([[1,2],[3,4]])

# Transpose karo
print(A.T)
# [[1, 3],
#  [2, 4]]

# Double transpose = original
print((A.T).T)     # [[1,2],[3,4]] — wapas same!

# Column vector ko row mein convert
v = np.array([[2],[5]])  # shape (2,1)
print(v.T)             # [[2, 5]]  — shape (1,2)

Dot Product — Vectors ka "Conversation"

Do vectors kitna similar direction mein point karte hain

📌 Definition

Dot product mein ek hi position ke numbers multiply karke sab add karte hain. Result ek scalar hota hai. a·b = a₁b₁ + a₂b₂

Example — [1, 2] · [3, 4]:

📐 Geometric Meaning

a·b = |a| × |b| × cos(θ)
• θ = 0°: same direction → max positive
• θ = 90°: perpendicular → 0
• θ = 180°: opposite → negative

🔍 Cosine Similarity

similarity = a·b / (|a| × |b|)

ML mein text/image similarity check karne ke liye use hota hai!

Python — Dot Product
a = np.array([1, 2])
b = np.array([3, 4])

# Method 1
print(np.dot(a, b))   # 11

# Method 2 (same result)
print(a @ b)          # 11

# Cosine Similarity
cos_sim = np.dot(a,b) / (np.linalg.norm(a) * np.linalg.norm(b))
print(cos_sim.round(3))  # 0.983 — almost same direction!

Python — Special Matrices
# Identity Matrix
I = np.eye(2)
print(I)         # [[1., 0.], [0., 1.]]

# Zero Matrix
Z = np.zeros((2,2))
print(Z)         # [[0., 0.], [0., 0.]]

# Diagonal Matrix
D = np.diag([5, 3])
print(D)         # [[5, 0], [0, 3]]

# Check Symmetric
A = np.array([[4,2],[2,3]])
print(np.allclose(A, A.T))  # True — symmetric hai!

# Identity se multiply
M = np.array([[1,2],[3,4]])
print(M @ I)     # [[1,2],[3,4]] — same as M!
